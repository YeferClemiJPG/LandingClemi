# CLEMI · Landing institucional NFC

Página principal de Fundación CLEMI, con el sistema visual compartido por las landings profesionales.

Sitio: https://yeferclemijpg.github.io/LandingClemi/

## Desarrollo

- npm ci
- npm run dev
- npm run verify
- npm run export:preview

Datos en content/profile.json. Plantilla en src/page.html. Estilos institucionales en src/institutional-theme.css. Exportación autónoma en artifacts/CLEMI_Vista_Previa.html. GitHub Pages despliega dist/ desde main.

Guardar contacto descarga una vCard. Su importación depende del dispositivo.

## Contenido y recursos

El lema fue proporcionado por el usuario. El contacto comercial y la descripción institucional proceden de [Contacto CLEMI](https://new.clemi.edu.co/contactenos/) y [Servicios CLEMI](https://new.clemi.edu.co/servicios/), consultados el 30/09/2026.

Logo oficial, fotografía de formación e ilustraciones decorativas reutilizados del sistema CLEMI aprobado. No se han generado imágenes nuevas para esta página. Las ilustraciones son decorativas y no acreditan instalaciones ni resultados médicos. Licencias incluidas en public/THIRD_PARTY_NOTICES.txt.

Las tres landings personales pendientes se trabajarán individualmente con los datos y fotografías que proporcione el usuario.
